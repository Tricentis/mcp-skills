# Commander MCP

When MCP tools for Tosca Commander are available:

1. Use **Code Mode** — plan tool sequences before execution (`/commander-mcp` skill).
2. **Data Integrity** — read `di-orchestration.md` and one `reference/di/` file before DI tools.
3. Save or check in after workspace mutations.
4. MCP endpoint: `http://127.0.0.1:<port>/mcp` — use port from Commander MCP settings (default **46248**; DEBUG often **8080**).
